# Orbis · Design & UX

## Визуальное направление

**Modern SaaS:** белые поверхности на светло-сером фоне, фирменный синий #3158d8, компактная типографика, единые состояния полей и кнопок, адаптивная верхняя навигация. Компоненты написаны на чистых CSS/JS, внешние CDN не используются.

## Пользовательские тексты

В интерфейсе не используются технические названия продукта/платформы, DTO, Person, Spring MVC, Hibernate и т. п. Название: **Orbis**; разделы: **Люди**, **Локации**, **Инструменты**, **История**. Подвал каждой страницы содержит точный текст:

> © 2026. Все права принадлежат Величайшему.

## Каталог людей

- На экране отдельная кнопка **Фильтры**, раскрывающая панель. Для имени и названия локации написано «полностью»: бэкенд использует точное равенство, не поиск подстроки. Цвет глаз, цвет волос и гражданство выбираются из перечней.
- Активные фильтры показываются чипами над таблицей; можно снять любой отдельно или очистить все.
- Сортировка состоит из поля и понятного направления («Сначала новые», «От А до Я», «От большего к меньшему»). Заголовки подходящих колонок тоже кликабельны.
- Таблица содержит каждый атрибут Person и вложенные свойства Location в отдельных колонках, а также компактное меню `⋯` без отдельного заголовка «Действия». Нажатие на строку или имя открывает карточку, `⋯` позволяет открыть, изменить или удалить запись. Меню показывается поверх таблицы и не обрезается при горизонтальной прокрутке. На мобильных таблица прокручивается горизонтально; поля не вырезаются.

## Локации и связи

- В таблице локаций показаны название, **ID** и координаты X/Y; визуальной колонки «Действия» больше нет.
- Нажатие на строку открывает отдельную карточку `/locations/{id}` с координатами и списком привязанных людей; имена людей ведут на их карточки.
- В меню `⋯` остаются действия «Открыть карточку», «Изменить», «Удалить».
- Кнопки редактирования и удаления также доступны на самой карточке; перенос связей при удалении сохраняется.

## Формы и действия

- Создание — отдельная страница. Изменение — модальное окно с такими же структурированными секциями.
- Значения enums перед отображением переводятся на русский (API и хранимые значения не меняются).
- Для удаления Person/Location и операции удаления по весу используется диалог подтверждения с конкретным действием.
- Инструменты показывают результат человеку, а не сырые JSON-ответы.
- История изменений имеет человеческие подписи; подробные технические данные можно открыть в раскрывающейся секции.
- Вход и регистрация используют одинаковую дизайн-систему. Пароли можно скрыть и показать.

## Технические контракты

Обновление не требует миграций. Для `/api/people` введён явный DTO с **прежней схемой JSON** вместо прямой сериализации `PageImpl`. CSRF и правила транзакций не менялись. Обновления по WebSocket обновляют текущий экран, не сбрасывая активные фильтры каталога.

## Проверки UI

1. Две вкладки: создание, обновление и удаление людей; realtime.
2. Фильтры: полное совпадение, чипы, удаление одного чипа, сброс.
3. Сортировка: имя, рост, дата создания; выбор направления и клик заголовка.
4. Вкладки: Локации, Инструменты, История, Карточка Person.
5. Разные размеры экрана (десктоп / телефон), сохранение горизонтальной прокрутки таблицы.
6. Валидация: ошибки при отрицательном весе, пустом имени, конфликте версии.
7. Вход и регистрация, просмотр/скрытие пароля, footer, отсутствие открытого доступа к API без сессии.
